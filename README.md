# 📖 القراءات السبع — رحلة للأطفال     (The Seven Readings — A Journey for Kids)
An interactive single-page web application (SPA) designed to introduce children to the science of Quranic Qiraat (The Seven & Ten Qiraat) through engaging visuals and interactive learning activities. Fully in arabic language

Developed for the course **QIRAAT AMALI II (QQQ3163)**.

## 🌟 Key Features

1. **Introduction & Interactive Timeline (Home)**
   - Explains the revelation of the Quran upon seven *ahruf* and the concept of *sanad* (transmission chain).
   - Interactive 5-step timeline covering transmission from Prophet Muhammad ﷺ through the Companions, Successors, the 10 Imams, and their Narrators.

2. **Interactive Flip Cards (The 7 & 10 Imams)**
   - 3D flip cards detailing each Imam's profile, city, year of death, key narrators, and historical facts.
   - Covers both the canonical Seven Imams and the additional Three Imams of the Ten Qiraat.

3. **Listen & Compare (Audio & Recitation Variants)**
   - Demonstrates differences in pronunciation across riwayat (e.g., Surah Al-Fatihah & Al-Baqarah).
   - Arabic text-to-speech pronunciation powered by the browser's native *Web Speech Synthesis API*.

4. **Journey Map of the Imams**
   - Geographical overview across 5 historic Islamic centers: Madinah, Makkah, Basra, Damascus, and Kufa.

5. **Matching Game**
   - Interactive matching game pairing each Imam with their primary narrator (*rawi*), complete with visual cues and sound effects.

6. **Frequently Asked Questions (FAQ)**
   - Collapsible accordion answering common questions children have about recitation variants and meanings.

7. **Knowledge Quiz & Printable Certificate**
   - Multiple-choice quiz with real-time scoring and star ratings.
   - Personalized certificate generator featuring student name and test scores, styled for direct printing via `@media print`.

8. **Built-in Audio Synthesizer**
   - Native sound engine using the browser's *Web Audio API* to generate interaction sound effects and gentle ambient background tones without external audio dependencies.

## 🛠️ Tech Stack

* **HTML5**: Semantic markup with right-to-left language orientation (`dir="rtl"`).
* **CSS3**: Custom properties, CSS Grid, Flexbox, 3D card flips, transitions, and print stylesheets (`@media print`).
* **JavaScript (Vanilla ES6)**: SPA tab routing, Web Audio API sound synthesis, and Web Speech API.
* **Google Fonts**: *Cairo*, *Aref Ruqaa*, and *Baloo Bhaijaan 2*.

## 🚀 Getting Started

This is a **zero-dependency, static client-side project**. No backend server or build pipeline is required.

1. Clone or download the repository.
2. Ensure the primary code file is named `index.html`.
3. Open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari).
4. Click the speaker icon (🔈 / 🔊) in the navigation bar to toggle interaction audio effects.
