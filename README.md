## 🌟 Key Features

1. **Introduction & Interactive Timeline (Home)**[cite: 1]
   - Explains the revelation of the Quran upon seven *ahruf* and the concept of *sanad* (transmission chain)[cite: 1].
   - Interactive 5-step timeline covering transmission from Prophet Muhammad ﷺ through the Companions, Successors, the 10 Imams, and their Narrators[cite: 1].

2. **Interactive Flip Cards (The 7 & 10 Imams)**[cite: 1]
   - 3D flip cards detailing each Imam's profile, city, year of death, key narrators, and historical facts[cite: 1].
   - Covers both the canonical Seven Imams and the additional Three Imams of the Ten Qiraat[cite: 1].

3. **Listen & Compare (Audio & Recitation Variants)**[cite: 1]
   - Demonstrates differences in pronunciation across riwayat (e.g., Surah Al-Fatihah & Al-Baqarah)[cite: 1].
   - Arabic text-to-speech pronunciation powered by the browser's native *Web Speech Synthesis API*[cite: 1].

4. **Journey Map of the Imams**[cite: 1]
   - Geographical overview across 5 historic Islamic centers: Madinah, Makkah, Basra, Damascus, and Kufa[cite: 1].

5. **Matching Game**[cite: 1]
   - Interactive matching game pairing each Imam with their primary narrator (*rawi*), complete with visual cues and sound effects[cite: 1].

6. **Frequently Asked Questions (FAQ)**[cite: 1]
   - Collapsible accordion answering common questions children have about recitation variants and meanings[cite: 1].

7. **Knowledge Quiz & Printable Certificate**[cite: 1]
   - Multiple-choice quiz with real-time scoring and star ratings[cite: 1].
   - Personalized certificate generator featuring student name and test scores, styled for direct printing via `@media print`[cite: 1].

8. **Built-in Audio Synthesizer**[cite: 1]
   - Native sound engine using the browser's *Web Audio API* to generate interaction sound effects and gentle ambient background tones without external audio dependencies[cite: 1].

This project was built with the assistance of **Artificial Intelligence (AI)** tools:
* **Code Scaffolding & UI Design**: AI was utilized to draft semantic HTML structures, responsive CSS layouts (Flexbox/Grid), and core JavaScript logic (state transitions, quiz logic, matching mechanisms, and Web Audio API integration)[cite: 1].
* **Content Structuring & Localization**: Child-friendly Arabic explanations, story narratives, and UI copy were structured with AI language models and subsequently reviewed for academic alignment with the course syllabus.

## 🛠️ Tech Stack

* **HTML5**: Semantic markup with right-to-left language orientation (`dir="rtl"`)[cite: 1].
* **CSS3**: Custom properties, CSS Grid, Flexbox, 3D card flips, transitions, and print stylesheets (`@media print`)[cite: 1].
* **JavaScript (Vanilla ES6)**: SPA tab routing, Web Audio API sound synthesis, and Web Speech API[cite: 1].
* **Google Fonts**: *Cairo*, *Aref Ruqaa*, and *Baloo Bhaijaan 2*[cite: 1].

## 🚀 Getting Started

This is a **zero-dependency, static client-side project**. No backend server or build pipeline is required.

1. Clone or download the repository.
2. Ensure the primary code file is named `index.html`[cite: 1].
3. Open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari)[cite: 1].
4. Click the speaker icon (🔈 / 🔊) in the navigation bar to toggle interaction audio effects[cite: 1].
